# daily1 视觉修正验收记录

Status: ready-for-agent
Date: 2026-10-30

实现已修正，390px 默认、选中及关闭三态的微信截图已取得并人工对照原型。375px 微信小屏补充检查仍待完成，规格保持 ready-for-agent；不宣称真机验收完成。

## 本次改动

- 照片上方移除新增眉题、大标题和说明，恢复原型的照片优先布局；适用范围和演示说明移到卡片下方。
- 恢复白背景、左右 20px 内容边距、16px 图片圆角。
- 标签恢复 12px/16px、5px 圆角和按文字收缩；显式覆盖微信 mini 按钮的字号、行高和内边距。
- 默认卡和选中卡共用浅灰背景、中性边框及 148px 最小高度；英文标题恢复 17px。
- 关闭改为透明背景 ×，点击区 36×36px；同样覆盖微信默认尺寸。
- daily1 叉子使用预览的向上偏移和 26px 引线，未改写历史 bbox，未实现通用避让或 anchor 校验。

## 已说明的平台与阶段差异

- 使用微信原生导航，排除原型模拟的状态栏、胶囊和 home indicator。
- 当前仅支持 daily1 四项，因此提示为“点标签查看释义”，没有未实现的圆点、收起和切换照片操作。
- 默认卡说明适配当前能力；卡片下方保留演示、适用照片和历史位置未验证说明。
- 系统字体栅格化可能产生小数像素差异；本次尺寸测量符合规格容差，不据此推断截图视觉一致。

## 验证与剩余项

- 页面模拟测试 4/4 通过；类型检查通过。
- 微信测量已覆盖标签字号/大小、图片比例、卡片大小及颜色、关闭尺寸；截图入口仍使用真实结果页，不另建假小程序画面。
- 早期截图接口 15 秒内未返回，桌面工具取得全黑截图。完整错误：`微信截图 15 秒内未返回；布局测量已保存，视觉验收未通过`。随后截图恢复，最新微信验收 1/1 通过，三态截图与 JSON 已保存；不再需要用户处理该截图问题。
- 截图失败后本轮不继续重试截图；自动化仍完成其余布局和交互断言，保存测量数据，并最终报告失败，避免掩盖截图缺失。
- 390px 三态截图已查看：照片首屏、紧凑标签、叉子引线、中性词卡和 × 均与基准结构一致，已说明的文案适配及来源说明保留；关闭恢复标签样式与位置，自动化断言通过。

## 复验

电脑解锁且工具窗口打开后，在工程根目录执行：

```powershell
& 'E:\soft\微信web开发者工具\cli.bat' auto --project 'F:\codexDemo\Annotation' --auto-port 9420
npm.cmd run test:wechat
```

入口会保存默认、选中 plastic cup、关闭三态的 JSON 与截图到 `evidence/`，并检查标签关闭后样式和位置恢复。微信接口返回的设备 pixelRatio 与导出 PNG 的尺寸可能不同；对照页按 390 CSS px 显示，不能直接用未归一化的图片像素比较。
