## 复验

电脑解锁且工具窗口打开后，在工程根目录执行：

```powershell
& 'E:\soft\微信web开发者工具\cli.bat' auto --project 'F:\codexDemo\Annotation' --auto-port 9420
npm.cmd run test:wechat
```

入口会保存默认、选中 plastic cup、关闭三态的 JSON 与截图到 `evidence/`，并检查标签关闭后样式和位置恢复。微信接口返回的设备 pixelRatio 与导出 PNG 的尺寸可能不同；对照页按 390 CSS px 显示，不能直接用未归一化的图片像素比较。

375px 复验时先在模拟器机型菜单选择 iPhone 6/7/8（本次使用真实 375px 窗口），再执行：

```powershell
$env:WECHAT_VIEWPORT='375'
npm.cmd run test:wechat
Remove-Item Env:WECHAT_VIEWPORT
```

小屏证据写入 `evidence/375/`；默认命令仍要求真实 390px，不会将 375px 截图写到主基准。切换机型后若截图桥接失效，可重新执行 `cli.bat auto` 连接当前窗口；本次重新连接后验收成功。早期 `390 !== 375` 的失败证明了尺寸核验入口可以阻止错误设备结果。
