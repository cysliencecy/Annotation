## 范围与实现

- 通过原型已有的“切换体验照片”按钮进入 flower1，两个已知照片各自绑定对应的原始结果，切换时重新初始化。
- 原 JSON 前五项展开，其余两项圆点；展开集合没有五项上限，允许全部收起及全部重开。
- 对象身份为样本 ID + 原始序号；七色沿用预览 `#d53939`、`#2461d9`、`#128247`、`#8734d0`、`#a75610`、`#a92975`、`#087d8b`。
- 点圆点不改选中词义，点英文才打开或切换；关闭保留所有展开状态；收起只影响当前对象。
- flower1 没有原始解释字段，词卡不显示解释段落，不补造说明；页面披露演示范围、排序依据和历史中心点未验证。
- 继续沿用结果页边界，不测试私有方法。原始 JSON、原照片不修改；生成小程序支持的 JS 模块。
