# 01 — 在小程序中查看日常样本与词义

Status: done
Date: 2026-10-30
Parent: [Development spec](../spec.md)

**What to build:** 学习者能在可运行的微信小程序中进入明确标记的 daily1 演示，完整看到原照片，点击其四个英文标签查看对应词义，并在标签之间切换或关闭卡片。

**Blocked by:** None — can start immediately.

- [x] 选定并记录适合当前单端需求的最小工程方案，小程序能按运行说明导入微信开发者工具、启动并进入演示页。
- [x] 结果页通过可替换的数据来源取得与 daily1 一一对应的 4 项原始结果；明确标识演示数据与历史 bbox 中心预览，说明位置尚未验证。
- [x] 页面说明适用照片是清晰、彼此分开的日常物体照；原图等比完整显示，四个英文与对应对象关联，不凑第 5 个，不提供“更多词汇”。
- [x] 每个对象具有稳定的会话身份和区分色；默认白底彩色文字，点击后同色底白字，无 √。不得因英文相同而意外合并不同记录。
- [x] 卡片显示选中对象的英文、中文名称和原有的一句简短解释；点击其他标签时只有一个选中对象、一张卡片。
- [x] 关闭卡片后四个英文保留，标签恢复默认样式；页面操作不改写原始 JSON。
- [x] 建立规格确认的页面级行为验收入口，覆盖演示装载、点击、切换与关闭；实际运行的页面与受控数据来源贯通，不以单独内部函数测试代替。
- [x] 记录开发者工具或真机运行的前置条件；缺少 AppID、登录或设备权限时如实指出，不能将浏览器页面当成已完成的小程序。

边界：本项先完成基本定位与词义查看；额外圆点、收起、严格 anchor 校验、引线和碰撞避让由后续任务逐步加入。对本项暂未实现的能力不作完成声明。
