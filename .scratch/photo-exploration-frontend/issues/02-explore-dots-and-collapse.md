# 02 — 通过圆点展开、收起并继续探索

Status: done
Date: 2026-10-30
Parent: [Development spec](../spec.md)

**What to build:** 学习者能从额外圆点发现已有英文，按两步查看词义，并自由收起、再次展开；已点开的其他标签持续保留。

**Blocked by:** 01 — 在小程序中查看日常样本与词义。

- [x] 加入 flower1 对应的 7 项历史演示，初始按原 JSON 顺序展开前 5 项，其余 2 项显示圆点；不声称已实现可靠性排序或扩展日常识别范围。
- [x] 点击两个额外圆点后，页面依次显示 6 标签 1 圆点、7 标签 0 圆点；已有标签保留，不以 5 个截断原始结果或当前展开集合。
- [x] 点击圆点只展开英文，不新开卡片、不请求识别；若已在查看其他对象，保留该卡片与选中对象。
- [x] 再点击新英文才查看其词义；花束记录没有简短解释时只展示原有字段，并在演示说明中披露，不补造模型解释。
- [x] 卡片中“收起标签”只将当前对象变回圆点并关闭其卡片；其他标签保持；再次点该圆点仍只展开英文。
- [x] 允许把所有标签收为圆点，再逐个全部展开；对象身份和颜色在整个过程中稳定。
- [x] 点击无标签、无圆点的位置不新增对象、不请求识别；页面级操作验收覆盖连续展开、词义切换、关闭、收起、全收起与再次展开。

边界：本项交付探索行为与状态，不以极端密集布局尚未确定为由新增词汇列表或自动收起其他标签。完整避让在 05 验收。
