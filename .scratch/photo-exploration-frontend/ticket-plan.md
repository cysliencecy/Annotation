## 01 — 在小程序中查看日常样本与词义

**What to build:** 学习者能在可运行的微信小程序中进入明确标记的 daily1 演示，完整看到原照片，点击其四个英文标签查看对应词义，并在标签之间切换或关闭卡片。

**Blocked by:** None — can start immediately.

**发布记录:** 已发布；当前开发状态见对应独立任务。

- [ ] 选定并记录适合当前单端需求的最小工程方案，小程序能按运行说明导入微信开发者工具、启动并进入演示页。
- [ ] 结果页通过可替换的数据来源取得与 daily1 一一对应的 4 项原始结果；明确标识演示数据与历史 bbox 中心预览，说明位置尚未验证。
- [ ] 页面说明适用照片是清晰、彼此分开的日常物体照；原图等比完整显示，四个英文与对应对象关联，不凑第 5 个，不提供“更多词汇”。
- [ ] 每个对象具有稳定的会话身份和区分色；默认白底彩色文字，点击后同色底白字，无 √。不得因英文相同而意外合并不同记录。
- [ ] 卡片显示选中对象的英文、中文名称和原有的一句简短解释；点击其他标签时只有一个选中对象、一张卡片。
- [ ] 关闭卡片后四个英文保留，标签恢复默认样式；页面操作不改写原始 JSON。
- [ ] 建立规格确认的页面级行为验收入口，覆盖演示装载、点击、切换与关闭；实际运行的页面与受控数据来源贯通，不以单独内部函数测试代替。
- [ ] 记录开发者工具或真机运行的前置条件；缺少 AppID、登录或设备权限时如实指出，不能将浏览器页面当成已完成的小程序。

边界：本项先完成基本定位与词义查看；额外圆点、收起、严格 anchor 校验、引线和碰撞避让由后续任务逐步加入。对本项暂未实现的能力不作完成声明。

## 02 — 通过圆点展开、收起并继续探索

**What to build:** 学习者能从额外圆点发现已有英文，按两步查看词义，并自由收起、再次展开；已点开的其他标签持续保留。

**Blocked by:** 01 — 在小程序中查看日常样本与词义。

**发布记录:** 已发布；当前开发状态见对应独立任务。

- [ ] 加入 flower1 对应的 7 项历史演示，初始按原 JSON 顺序展开前 5 项，其余 2 项显示圆点；不声称已实现可靠性排序或扩展日常识别范围。
- [ ] 点击两个额外圆点后，页面依次显示 6 标签 1 圆点、7 标签 0 圆点；已有标签保留，不以 5 个截断原始结果或当前展开集合。
- [ ] 点击圆点只展开英文，不新开卡片、不请求识别；若已在查看其他对象，保留该卡片与选中对象。
- [ ] 再点击新英文才查看其词义；花束记录没有简短解释时只展示原有字段，并在演示说明中披露，不补造模型解释。
- [ ] 卡片中“收起标签”只将当前对象变回圆点并关闭其卡片；其他标签保持；再次点该圆点仍只展开英文。
- [ ] 允许把所有标签收为圆点，再逐个全部展开；对象身份和颜色在整个过程中稳定。
- [ ] 点击无标签、无圆点的位置不新增对象、不请求识别；页面级操作验收覆盖连续展开、词义切换、关闭、收起、全收起与再次展开。

边界：本项交付探索行为与状态，不以极端密集布局尚未确定为由新增词汇列表或自动收起其他标签。完整避让在 05 验收。

## 03 — 从微信相册选图并安全切换照片

**What to build:** 学习者能用真实微信相册选择和完整预览自己的照片，也能回到演示样本；取消选择保留当前会话，新照片不出现无关样本标签。

**Blocked by:** 01 — 在小程序中查看日常样本与词义。

**发布记录:** 已发布；当前开发状态见对应独立任务。

- [ ] 从页面进入微信相册选取一张图片，在小程序中完整等比预览，不新增相机拍摄入口。
- [ ] 取消选图不清空原照片、结果、当前卡片或已存在的页面状态；平台选择失败有可理解提示并可重新选择。
- [ ] 演示入口和真实选图入口明确区分；预置结果只关联自己的演示照片，不能按任意照片、文件名或选择顺序套用样本 JSON。
- [ ] 对本阶段无法取得匹配结果的新照片，明确说明识别服务尚未接入；不显示随机标签，不伪装成模型识别失败或无物体。
- [ ] 切回演示照片时装载对应照片与一份新的结果会话，不混用旧对象身份、选中对象或标签。
- [ ] 页面级验收通过替代的相册边界检查选择、取消与错误；在微信平台实际确认选图、取消和预览，并记录执行环境。

边界：本项让照片选择与结果会话分开，不接真实识别，不负责异步迟到结果的完整处理；请求隔离在 06 验收。

## 04 — 使用有效指向点展示小物体与定位异常

**What to build:** 学习者能在对应照片上看到有有效 anchor 的图上标签，小物体通过引线清楚关联；位置或格式有问题时看到异常状态，而不是错误的假指向。

**Blocked by:** 01 — 在小程序中查看日常样本与词义。

**发布记录:** 已发布；当前开发状态见对应独立任务。

- [ ] 从受控结果来源向页面提供明确标识的模拟新格式数据，验证英文、中文、简短解释、bbox 与 anchor 的契约；模拟数据不保存为真实模型输出。
- [ ] 图片按实际显示区域的宽、高及偏移映射 0–1000 坐标，容器留白不参与映射，图片不裁切、不拉伸。
- [ ] 新结果的 anchor 必须为范围内的数值并落在有效 bbox 内；缺失或非法时不静默回退 bbox 中心，不为该对象画标签或圆点。
- [ ] 历史演示保留显式的 bbox 中心兼容方式及未验证说明；新格式校验与历史兼容不混用，原始数据保持原样。
- [ ] 文字首选位置与指向点分开；小物体文字移到旁边，同色引线回到原有效点，不扩大 bbox 或移动 anchor 给文字让位。
- [ ] 受控数据里无可展示位置或整体格式不符合契约时，页面显示明确的定位或格式异常，不制造成功数量和占位对象。
- [ ] 通过页面验证有效 anchor、历史中心点、缺 anchor、越界、反向 bbox、框外 anchor、小目标引线及不同图片比例；不以几何校验通过宣称语义定位准确。

边界：本项实现基本指向与异常呈现，恢复入口的完整重试流程在 06 完成，多目标碰撞和尺寸变化在 05 完成。

## 05 — 在不同手机尺寸上避让标签和圆点

**What to build:** 学习者展开多个英文后，仍能在支持的手机尺寸上读清标签、点击额外圆点，并通过引线找到目标。

**Blocked by:** 02 — 通过圆点展开、收起并继续探索；04 — 使用有效指向点展示小物体与定位异常。

**发布记录:** 已发布；当前开发状态见对应独立任务。

- [ ] 在 daily1 四项及 flower1 七项演示中，布局考虑已展开文字、剩余圆点和图片边界；可清楚摆放时无文字重叠、标签裁切或圆点被文字遮住。
- [ ] 标签首选目标中心，需要避让时移到旁边；为移开的标签绘制同色引线，目标指向仍对应原有效点。
- [ ] 继续展开第 6、第 7 个或收起一个标签后重新排版，其余对象的展开、选中、身份及颜色不变。
- [ ] 显示尺寸或图片区域改变后按新区域重新映射与排版，不重置探索会话，不重新截断到 5 个，不改变模型坐标。
- [ ] 在明确记录的支持尺寸上通过页面行为、截图及触控检查；点得到的圆点与标签实际触发正确对象，不以固定像素位置快照代替正确性。
- [ ] 对避让仍无法解决的密集案例保留证据，明确列为未决，不擅自新增“更多词汇”、强行叠字、自动收起其他标签或改变目标点。
- [ ] 页面验收覆盖边缘目标、小目标、连续展开、剩余圆点可点击以及尺寸变化前后的状态保留；人工检查复杂背景的对比和对应关系。

## 06 — 从加载或异常中重试并隔离旧请求

**What to build:** 学习者能理解结果加载、失败或无可展示对象的状态并重试、换图；快速切换或重试时，旧请求不会把错误照片或旧结果覆盖到当前页面。

**Blocked by:** 02 — 通过圆点展开、收起并继续探索；03 — 从微信相册选图并安全切换照片；04 — 使用有效指向点展示小物体与定位异常。

**发布记录:** 已发布；当前开发状态见对应独立任务。

- [ ] 通过可替换的受控演示结果来源展示等待结果、调用失败、空结果、格式异常和定位异常；相册新照片的服务未接入状态与这些状态分开。
- [ ] 可恢复的异常提供重试与换图入口，操作真实作用于当前照片会话；成功取得新结果后重新初始化初始标签与圆点，清除旧选中。
- [ ] 对已经展开额外标签、打开词卡的会话重试成功后，不携带旧展开集合、旧卡片或旧对象身份。
- [ ] 请求 A 未结束时换到 B，A 迟到的成功或失败都不能覆盖 B 的照片、结果、加载或异常提示。
- [ ] 同一照片连续发起请求时，仅当前请求的结果更新页面；不能依赖不可控的返回顺序，不通过阻止正常换图回避问题。
- [ ] 结果没有可展示对象时明确提示，不伪造标签、圆点、置信度或错误的成功数量；数据完整性保持，不能把异常输出人工修成正确结果。
- [ ] 开发控制的延迟、失败和返回顺序只用于验收，不混入正常学习流程，不宣称演示重试实际调用 GLM。
- [ ] 页面级验收贯通失败后重试、空或非法结果恢复、换图、请求 A/B 成功与失败乱序，以及新结果初始化；记录微信环境的实际运行结果与尚未具备的真机条件。

## 规格覆盖与交付判断

- 01 覆盖第一张演示、基本词义卡片、单选颜色、关闭保留及页面验收入口。
- 02 覆盖五标签两圆点、两步查看、所有展开/收起转换、无标记区域点击及颜色稳定性。
- 03 覆盖相册、取消、照片完整预览，以及新照片不套用演示 JSON。
- 04 覆盖新结果契约、历史预览兼容、几何映射、基本小目标引线及无效位置呈现。
- 05 覆盖多目标避让、图片边界、圆点可点击性、复杂背景和尺寸变化后的状态保留。
- 06 覆盖加载、数据来源失败、空或非法结果的恢复、重试初始化及迟到请求隔离。

测试随各项交付，沿用已确认的结果页行为边界，不把所有检查推迟到最后。全部六项完成后，仍需对照父规格确认小程序的整体适用场景已跑通；浏览器原型通过、单张截图或历史模型结果不替代微信环境验收。

识别总数上限、极端拥挤处理、真实模型调用及 Figma 完善不在本次任务中增加隐含承诺。真机验收如需项目 AppID、微信登录或设备权限，应明确记录所需条件，不虚报已完成。
