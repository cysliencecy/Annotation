# 识图结果可视化

本地 Python 脚本，读取原图和模型 JSON，绘制边界框及英文名称并另存图片。不调用 API，不使用生图模型，不修改原图，也不按场景上限截断结果，以便发现模型超量输出。现有离线提示词中，食物、日常和风景最多 5 项，鲜花最多 10 种；[当前 MVP](MVP定义.md)的“初始展开最多 5 个”是展示规则，日常识别总数上限仍待确认。

## 使用

安装 Python 3.10 或更新版本，然后在项目根目录运行：

```powershell
python -m pip install -r requirements.txt
python visualize.py images/food1.jpg results/food/food1-v2.json -o outputs/food/food1-check.png
```

把实际模型输出保存为 UTF-8 编码的 JSON，放在 `results/food/`、`results/daily/`、`results/scenery/` 或 `results/flowers/`；例如 `results/food/food1-r3.json`。只保留 JSON 本身，不带 Markdown 代码围栏或额外说明。

默认支持对象数组，或 `{"objects": [...]}`。数组内每个对象使用 `name_en`（英文名称）和 `bbox`（边界框）；`name_zh`、`description` 不参与绘制。默认回绘也不使用 `anchor`；加上 `--show-anchor` 后，每项必须有该字段，脚本会校验其格式、范围和是否在自身 bbox 内，并在图中画点。点是否真的指对对象仍需人工对照原图。以下仅展示结构，并非真实识别结果：

```json
{"objects": [{"name_zh": "苹果", "name_en": "apple", "description": "苹果是一种常见的水果。", "bbox": [100, 150, 400, 500], "anchor": [250, 325]}]}
```

若实际字段是 `items`、`name_en` 和 `box`，无需改 JSON，可运行：

```powershell
python visualize.py images/food1.jpg results/food/food1-v2.json -o outputs/food/food1-check.png --items-key items --label-key name_en --box-key box
```

## 中心标签预览

检查模型返回的真实指向点，可单独运行（新输出名避免覆盖）：

```powershell
python visualize.py images/food3.jpg results/food/food3-anchor-r1.json -o outputs/food/food3-anchor-check.png --show-anchor
```

彩色圆点是模型给的 `anchor`，不是 bbox 中心，也不是最终文字位置。脚本尚不绘制引线或自动处理标签碰撞；几何校验通过不等于点落在正确物体上。

默认仍在框上缘显示标签。添加 `--label-position center`，将英文标签放到 bbox 中心；同时添加 `--hide-boxes`，只显示标签，便于观察实际指向和遮挡：

```powershell
python visualize.py images/flower1.JPG results/flowers/flower1-v2.json -o outputs/flowers/flower1-center.png --label-position center --hide-boxes
```

本机若默认 `python` 是 Python 2.7，可使用现有解释器：

```powershell
& 'C:/Users/18270/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/python.exe' visualize.py images/flower1.JPG results/flowers/flower1-v2.json -o outputs/flowers/flower1-center.png --label-position center --hide-boxes
```

中心取像素框的 `(xmin + xmax) / 2, (ymin + ymax) / 2`，文字底板以该点为中心摆放；靠近图片边缘时会向图内平移底板以避免裁掉文字。此模式不修改模型坐标，也不自动避让标签，保留重叠供人工判断。去掉 `--hide-boxes` 可同时显示框辅助检查。

逐张观察：标签是否指向其名称所对应的对象、标签是否相互重叠、文字是否挡住主要辨认特征。名称错误或坐标偏移应记录为模型问题；仅因标签底板遮挡而看不清应记录为显示问题。静态图片只能验证位置和粗略布局，不能验证点击体验或小程序实际屏幕效果。

## 坐标规则

边界框顺序为 `[xmin, ymin, xmax, ymax]`，每个数值范围为 0–1000。以左上角为原点，x 向右、y 向下：`x像素 = round(x × 原图宽 / 1000)`，`y像素 = round(y × 原图高 / 1000)`。1000 对应图片边缘，绘制时限制到最后一个有效像素。

脚本按照片 EXIF 信息纠正显示方向，坐标应基于模型看到的同方向完整原图。如果模型输入经过裁剪，优先对裁剪后的同一张输入图片回绘；若要画回未裁剪原图，必须先换算坐标。图片尺寸保持为纠正方向后的原始尺寸，建议输出 PNG，避免再次有损压缩。

越界、反向框、缺字段等错误会直接报错，不自动修正模型结果。输出文件已存在时会拒绝覆盖，请换一个输出名称。标签重叠可能仍需人工检查；本脚本仅供定位验证。

每类当前提示词和合并复测记录见[项目入口](../README.md)。后续回绘使用新的运行编号，不覆盖已有结果；相应观察追加到该类汇总记录。
