# 风景照识图方案讨论记录

## 已确认

- 天空、水面、山体、树林等连续的大范围场景区域可以使用较大的范围标注；标签应放在区域内清楚的位置，不再强制使用范围的几何中心。具体摆放见[共用标签展示规则](标签展示.md)。
- 有清楚近景物体时，优先选择近景物体；无近景物体时按显眼程度和边界清晰度选择单体与区域。
- 图片标签只使用能够指向具体对象或场景区域的名词，例如 sun、sky、water、mountain。sunset、scenery、view 等描述整幅画面的概念不作为图上标签；未来需要时可放在场景标题或摘要中。用户确认接受。
- 每张最多 5 个标签；先选择清楚可辨的近景物体，同类去重；名额有余时再补充清楚可辨的风景区域。不凑满 5 个。用户确认接受。
- 没有近景物体时，先选画面显眼且边界容易辨认的单体（如太阳），再选容易区分的场景区域（如水面、天空）；远处建筑仅在能明确辨认时加入。用户确认接受。
- 连成一片的同类风景区域只标一次，例如整段连续山脉用一个 mountain range 标签；分散的同类单体只选一个代表，例如多棵树只选一棵清楚的树。若树木连成边界可辨的树林，可把一片树林作为 forest 区域；不把多片不相连树丛合为一个大区域。用户确认接受。
- 场景区域与其中清楚可辨、可独立学习的对象可以同时标注，例如 sky 与其中的 cloud；显示端需要处理两个标签的避让，二者不是重复项。用户选择方案 A。
- 远处成排或密集的建筑、桥等人工物体，按单体同类物体处理：只选一个清楚的代表，不把整排合成一个标签。用户选择方案 A。
- 命名沿用保守命名规则：名称具体到照片有依据支持的程度；不猜具体地点或无法确认的地貌细类。例如能确认山脉时用 mountain range，无法判断湖或河时用 water。用户确认接受。

## 样本观察

- scenery1 没有明确近景单体，主要可见水面、天空、太阳及远处建筑。
- scenery2 有近景饮料杯，远处有山体、树林、天空和云。
- scenery3 有清楚的近景摩托车，另有道路和树林。

以上规则是产品约定，不是模型能力测试结论。此前 scenery1 至 scenery3 已完成回绘检查，见[风景复测记录](../reviews/风景.md)；[当前提示词](../prompts/风景.md)新增 anchor 后尚未实测。
