# 照片探索：临时交互预览

直接用浏览器打开 `index.html`，无需安装或联网。该目录是用于评估已确认交互的临时原型，不是产品实现。

方案已通过讨论确认，尚未经过用户试用：先显示最多 5 个英文，其余物体显示圆点；点击圆点只展开英文；再点击英文显示释义；关闭释义保留标签；收起标签变回圆点；其他已展开标签继续保留。标签使用不同颜色，选中后同色底白字，没有勾选图标。文字可避让并通过引线指向物体。

原始数据来自 `results/daily/daily1-v2.json` 与 `results/flowers/flower1-v2.json`。照片是原图；未修改模型名称。历史结果没有 anchor，点位使用 bbox 中心，名称与定位均未验证。花束样本仅演示超过 5 项的交互，不扩大日常 MVP 范围。模型没有提供置信度，因此样本先显示原 JSON 的前 5 项，并未实现识别优先级排序。

目前没有接入选图或识别服务；「切换体验照片」仅在两个预置样本间切换。状态只保存在内存中，刷新页面恢复初始状态。
